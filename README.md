# CodeAlpha Phishing Awareness Training

An interactive web module on phishing, built for the CodeAlpha Cyber Security internship (Task 2).

## Contents
- Clickable fake email with red flags to find
- Types of phishing and social engineering tactics
- How to spot fake websites
- Real-world examples and protection tips
- 5-question quiz

## How to use
Open index.html in any web browser.
